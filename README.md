# Models for cooperative interactions in microbial communities
The Mathematica notebooks listed below contain code that are used for numerical implementations of different cooperative ecological phenomena. These implementations create figures in the preprint article "Droste MJ, Planqué R, Bruggeman FJ (2026) - Emergent metabolic cooperation in communities of microbes that maximise growth rate by optimal protein expression". The corresponding release can be found on Zenodo.

- **Models for cooperative ecological phenomena.nb**: Mathematica code for implementation of the models for different cooperative ecological phenomena. For each phenomenon, we implement a variant of the growth rate maximisation problem that compares the growth rate of two different microbial populations. 
- **Facultative syntrophy for reduced model.nb**: Mathematica code for implementation of the reduced model for facultative syntrophy, where we assume the consuming species to be a passive consumer of the exchange metabolite.
